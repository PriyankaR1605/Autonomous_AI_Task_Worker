# CentrAlign Enterprise Big Dataset — Single-File Catalog

This directory contains consolidated, single-file tabular datasets for each corporate domain, as well as a unified master file covering all domains.

| Domain | File (CSV) | File (JSON) | Record Count | Description |
| :--- | :--- | :--- | :---: | :--- |
| **Invoices** | [`invoices_master_table.csv`](invoices_master_table.csv) | [`invoices_master_table.json`](invoices_master_table.json) | 50 | Master accounts payable & receivable table for all vendors, clients & staff |
| **Employees** | [`employees_master_table.csv`](employees_master_table.csv) | [`employees_master_table.json`](employees_master_table.json) | 60 | Complete enterprise staff directory across 10 departments |
| **Leave Requests** | [`leave_requests_master_table.csv`](leave_requests_master_table.csv) | [`leave_requests_master_table.json`](leave_requests_master_table.json) | 20 | PTO vacation, sick, and personal leave claims |
| **ITSM Tickets** | [`support_tickets_master_table.csv`](support_tickets_master_table.csv) | [`support_tickets_master_table.json`](support_tickets_master_table.json) | 15 | Helpdesk tickets with SLAs, priorities P1-P4, assignees |
| **Inventory** | [`inventory_master_table.csv`](inventory_master_table.csv) | [`inventory_master_table.json`](inventory_master_table.json) | 25 | Hardware, server, network, and office asset catalog |
| **Expenses** | [`expenses_master_table.csv`](expenses_master_table.csv) | [`expenses_master_table.json`](expenses_master_table.json) | 15 | Corporate reimbursement claims & supervisor approval tiers |
| **CRM Accounts** | [`customers_crm_master_table.csv`](customers_crm_master_table.csv) | [`customers_crm_master_table.json`](customers_crm_master_table.json) | 15 | Enterprise clients, ARR contracts, health scores |
| **Sales Pipeline** | [`deals_master_table.csv`](deals_master_table.csv) | [`deals_master_table.json`](deals_master_table.json) | 10 | Active and closed sales opportunities |
| **Departments** | [`departments_master_table.csv`](departments_master_table.csv) | [`departments_master_table.json`](departments_master_table.json) | 10 | Department heads, Q3 budgets, and spent amounts |
| **Purchase Orders** | [`purchase_orders_master_table.csv`](purchase_orders_master_table.csv) | [`purchase_orders_master_table.json`](purchase_orders_master_table.json) | 8 | Procurement orders issued to preferred suppliers |
